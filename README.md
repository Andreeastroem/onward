# Onward

Onward is a design project for a 3D, fixed-isometric real-time strategy game about ant colonies competing to survive in a living ecosystem.

All documentation is a static HTML website. Open [docs/index.html](docs/index.html) in a browser (no build step or server needed).

Documentation is written as HTML under `docs/`, not Markdown. Anything that documents something must follow the local skill in [.github/skills/html-docs/SKILL.md](.github/skills/html-docs/SKILL.md), also available to Claude through `.claude/skills/html-docs`.
